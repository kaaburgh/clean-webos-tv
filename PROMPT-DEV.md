# Промпт: цикл разработки webOS-приложения на настоящем ТВ

Второй режим репозитория. Телевизор в Developer Mode, агент сам собирает приложение, ставит его на ТВ,
запускает, подключается к нему через DevTools и проверяет результат: читает консоль и сетевые
запросы (в том числе фрагменты hls.js), смотрит DOM и диагностическую панель, делает скриншоты,
выполняет JS и нажимает кнопки пульта. Получается полный цикл: собрал, поставил на ТВ, сам проверил.

Профиль по умолчанию: [`kaaburgh/kinopub.webos`](https://github.com/kaaburgh/kinopub.webos) на LG G5
(`profiles/kinopub.webos.md`). Для другого приложения напишите такой же профиль.

Один раз на ТВ и компьютере (подробно в `docs/build-and-install.md` репозитория kinopub.webos):
- Developer Mode из LG Content Store, вход в аккаунт LG Developer, **Dev Mode Status** включён (ТВ
  перезагрузится), **Key Server** включён на время получения ключа.
- `ares-setup-device` (IP ТВ, порт 9922, пользователь `prisoner`, имя `lg-g5`), затем
  `ares-novacom --device lg-g5 --getkey` с паролем из приложения Developer Mode.
- Сессия Developer Mode живёт ограниченное время. Продлевайте её кнопкой EXTEND в приложении.

---

Работай в цикле разработки с моим LG webOS TV. Приложение: <ПУТЬ К РЕПОЗИТОРИЮ, по умолчанию
kinopub.webos>, ares-устройство: <ИМЯ, по умолчанию lg-g5>, IP ТВ: <IP>. Инструменты лежат в
клоне `https://github.com/kaaburgh/clean-webos-tv` (дальше `$CWT`). Прочитай `$CWT/profiles/<app>.md`,
если он есть, и правила самого репозитория приложения (AGENTS.md, CLAUDE.md) до любых изменений.

Подготовка
- `ares-device --system-info --device lg-g5` должен ответить. Если нет: проверь, что Developer Mode
  включён и сессия не истекла, и скажи мне, что сделать на ТВ. Не меняй настройки устройства сам.
- Для пульта и полноэкранных скриншотов подключи сетевой API: venv, `pip install -r $CWT/tools/requirements.txt`,
  `TV_HOST=<IP> $CWT/tools/lgtv.py pair` (я приму запрос на ТВ).

Цикл (из корня репозитория приложения)
1. Сборка, установка, запуск, DevTools одной командой:
   `ARES_DEVICE=lg-g5 $CWT/tools/devloop.sh` (флаги: `--skip-build`, `--no-inspect`, `--params JSON`).
   Скрипт делает `yarn build`, `yarn package`, `ares-install`, перезапуск через `ares-launch`, затем
   `$CWT/tools/inspect.sh`. Тот держит `ares-inspect` в фоне и пишет адрес DevTools в `.devtools-endpoint`.
   Если сборка падает, чини её как обычно; на ТВ без успешной сборки не ходи.
2. Проверка через DevTools (`$CWT/tools/devtools.py`, без зависимостей):
   - `console --seconds 30 [--grep hls]`: консоль, исключения и записи браузерного лога.
   - `network --seconds 30 --grep .ts`: запросы плейлистов и фрагментов, статусы, размеры, ошибки.
   - `eval 'выражение'` или `run файл.js`: состояние приложения и `<video>`.
   - `dom 'селектор' --text`: текст элемента, например диагностической панели.
   - `screenshot shots/NN.png`: веб-слой приложения. **Видео на нём чёрное**: оно идёт аппаратным
     слоем. Полный экран с видео даёт `lgtv.py screenshot` (если прошивка разрешает; защищённый
     контент тоже чёрный).
3. Пульт. Три способа, от самого честного к самому удобному:
   - `lgtv.py button DOWN ENTER BACK`: настоящие кнопки через сетевой API ТВ, как с пульта.
   - `devtools.py key Down Enter Back`: доверенные key-события через `Input.dispatchKeyEvent`
     с кодами webOS (Back=461, Blue=406, Play=415 и т.д., или числовой keyCode).
   - `devtools.py key ... --synthetic`: синтетический `KeyboardEvent` из JS, если первые два не
     доходят до обработчика.
   В приложении в Developer Mode нет root, поэтому `luna-send` из jail-шелла `prisoner` для пульта не
   подходит. Его роль здесь играет сетевой API (`lgtv.py`).
   Нажимай немного кнопок за раз и после каждой серии смотри на скриншот или DOM.
4. Сравни результат с ожиданием: что должно было измениться для пользователя. Если не совпало,
   сначала собери доказательства (консоль, сеть, панель диагностики, скриншот), потом меняй код.
   Каждый вывод подкрепляй тем, что видел на ТВ, а не тем, что должно было произойти.
5. Повтори цикл. Скриншоты и логи складывай в `shots/` и `logs/` вне репозитория приложения или в
   его `.gitignore`. Не коммить их.

Отчёт
- Что проверено на ТВ и чем (команда и её вывод или скриншот), что не удалось проверить и почему.
- Разделяй «проверено на G5» и «проверено в браузере/тестах». Ручные проверки из ROADMAP/issue
  закрывай только тем, что действительно прогнал на ТВ.

Завершение
- `$CWT/tools/inspect.sh --stop` закрывает DevTools-туннель.
- Не выключай Developer Mode без меня: он нужен для следующих циклов. Напомни про продление сессии,
  если до её конца меньше суток.
