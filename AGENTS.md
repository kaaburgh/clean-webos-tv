# Правила для агентов

Репозиторий: инструменты и промпты, чтобы агент работал с настоящим LG webOS TV.

- Режим очистки ТВ: следуйте [PROMPT.md](./PROMPT.md). Режим разработки приложения на ТВ:
  [PROMPT-DEV.md](./PROMPT-DEV.md) и профиль из `profiles/`.
- Пользуйтесь `tools/`, а не пишите свои клиенты: в них есть журнал изменений для отката и проверка
  записи чтением.
- Ничего не меняйте на ТВ без резервной копии (`tools/backup.sh`). Каждое изменение настройки идёт
  через `lgtv.py settings-set --log`, каждое изменение через меню записывается в `manual.md`.
- Проверяйте результат на устройстве (скриншот, чтение настроек, DOM, консоль) и в отчёте отделяйте
  проверенное от предположений.
- Не пытайтесь получить root, обойти защиту прошивки или Developer Mode, не сканируйте чужие сети.
- `~/.config/clean-webos-tv/keys.json` и ключи `ares-novacom` дают управление ТВ: не коммитьте и не
  публикуйте их.

Изменения в самом репозитории: `python3 -m unittest discover -s tests` (тесты `lgtv.py` против
фейкового ТВ нужны `pip install -r tools/requirements.txt`), `shellcheck tools/*.sh`.
