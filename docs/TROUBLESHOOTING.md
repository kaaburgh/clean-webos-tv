# Если что-то не так

**`lgtv.py` не подключается.** Проверьте IP (`TV_HOST`), что ТВ включён и что включён LG Connect
Apps. Новые прошивки слушают только `wss://TV:3001` (по умолчанию). Старые слушают `ws://TV:3000`:
`TV_NO_SSL=1`. Если ТВ в режиме ожидания, сеть может быть выключена; включите его пультом.

**Запрос сопряжения не появляется или ключ перестал подходить.** Удалите запись для IP в
`~/.config/clean-webos-tv/keys.json` и выполните `lgtv.py pair` снова. После сброса ТВ к заводским
настройкам старый ключ недействителен.

**`settings-set` печатает непустой `not_applied`.** Либо ключа нет в этой прошивке, либо LG закрыл
«alert-трюк». Ничего не повторяйте: сделайте это через меню пультом и запишите в `manual.md`.

**Скриншот пустой или чёрный.** `tv/executeOneShot` не снимает защищённое видео и Live TV, а на
некоторых прошивках может быть запрещён. В режиме разработки веб-слой приложения снимает
`devtools.py screenshot`, но видео там всегда чёрное (аппаратный слой).

**`ares-device` не отвечает.** Developer Mode выключен или сессия истекла (откройте приложение
Developer Mode, проверьте Dev Mode Status и Remain Session). После повторного включения может
понадобиться заново `ares-novacom --device lg-g5 --getkey` при включённом Key Server.

**`inspect.sh` не находит адрес DevTools.** Посмотрите `.ares-inspect.log` в корне clean-webos-tv. Проверьте, что
приложение установлено и запущено (`ares-launch --running --device lg-g5`). Если локальный
`@webosose/ares-cli` не работает с ТВ, поставьте `@webos-tools/cli` глобально и запустите с
`ARES_GLOBAL=1`.

**Кнопки из `devtools.py key` не доходят до приложения.** Фокус может быть вне документа
(системное меню поверх приложения). Нажмите кнопку через `lgtv.py button`, а для JS-обработчиков
попробуйте `--synthetic`.

**Скриншот падает с `CERTIFICATE_VERIFY_FAILED`.** На некоторых LG webOS `tv/executeOneShot`
возвращает HTTPS-ссылку с локально выданным сертификатом. `lgtv.py screenshot` допускает такой
сертификат **только при загрузке скриншота с IP/имени сопряжённого ТВ**, не отключая системную
проверку TLS. При использовании имени телевизора IP из ответа сверяется с адресами, на которые
разрешается это имя. Прокси для запроса не используется, перенаправления и ссылки на
посторонние хосты отклоняются. Если ТВ возвращает другой адрес, проверьте `TV_HOST`/`--host`,
а не отключайте SSL-проверку глобально.
